# Sam AI Slides Web

NotebookLM PPTX 瀏覽器編輯器，整合 HANBELL 快捷樣式、Gemini 單頁文字修改與可編輯 PPTX 匯出。

## 網頁入口
https://samliang0729-alt.github.io/Sam-AI/slides/

## 特性
- PPTX 在瀏覽器本機解析
- 可修改文字、圖片位置、尺寸、字色與字級
- Gemini API 單頁改稿
- HANBELL Standard / Tech 快捷樣式
- 匯出新的可編輯 PPTX

## 注意
此 Web 版優先服務 NotebookLM / image-heavy PPTX。SmartArt、動畫、OLE 與複雜 Chart 的完整 round-trip 仍以 Sam AI Slides RC 桌面版為主。
