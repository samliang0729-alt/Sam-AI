# Sam的AI開發

依五大類集中管理程式作品，提供網站與 GitHub 入口。

## 分類

- 財務、人事、總務
- 銷售、售服
- 生產、採購、倉儲
- 經營管理
- 個人小程序

## 使用

開啟 index.html，或透過 GitHub Pages 瀏覽。無需安裝套件或建置。
支援搜尋、新增、編輯、刪除程式入口，以及 JSON 備份匯入與匯出。
右上角可切換深色／淺色樣式，偏好會儲存在目前瀏覽器，重新開啟仍沿用。

管理修改僅儲存在目前瀏覽器，不會修改 GitHub，也不會同步到其他裝置。
要更新所有訪客看到的內容，使用「匯出目前網站」，將下載的 HTML 作為新的 index.html 提交至本專案。

GitHub 私有儲存庫需要具權限的登入帳號；公司內網程式需要連接公司網路。
安巡智控與 n8n-order 網站網址尚待設定，n8n-order 用途與分類待確認。

## GitHub Pages

在 Settings → Pages 選擇 Deploy from a branch，分支 main、目錄 / (root)。
網站首頁為 index.html。發布前請確認程式名稱、簡介與儲存庫連結適合提供網站訪客查看。
